🛠 ADMIN

People, connections, and data. Every destructive action takes a full export first — nothing here can lose something without handing it back to you on the way out.

👤 PEOPLE

Rename keeps a person's history with them. Replace does not — a different person does not inherit someone else's logged feelings. The two are separate on purpose.

🔗 CO-CREATION CONNECTION

Clears the pair: partner mirrors, shared namespace, outbox, pipeline code, invite state, and the crypto identity keys so the next connection handshakes fresh. Neither person's own journal, vault, codex or feeling history is touched — those are individual, not shared.

🌐 SERVER ADDRESS

What invite links and QR codes actually point to. Real, live-editable — changes here write straight to the server's own config, no restart needed for the next invite you generate. Leaving it blank falls back to whatever address your own browser is on right now, which is only right if you're generating the invite from the same place a guest would actually connect to.
